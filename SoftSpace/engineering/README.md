## Reproduction limits

Scripts preserve their research context. Dependencies and private local workspace paths are not bundled; some historical scripts require the original project layout or reconstruction using the publication manifest. Results must be read with the revision, model assumptions and source hashes that produced them. Syntax and publication integrity checks do not mean every historical script has been rerun successfully.

Do not automatically execute legacy builders or long solvers when inspecting this archive. Reopening development requires an explicit new owner request.

# Contributing to SoftSpace

This is a research prototype. Contributions should improve evidence, traceability or a concrete design problem.

For measurements, include the product/model, sample or material grade, units, apparatus, method, environmental conditions, repeated observations and uncertainty. State consent and anonymize wearer feedback; do not upload personal health information.

For numerical changes, retain the original result, identify the source CAD by hash, state material/contact/boundary assumptions, record solver failures, and check numerical sensitivity where appropriate. A solver pass is not a physical-validation pass.

Update **both living reports** when a meaningful design change or new result affects the shared project. Explain when one product route is unchanged. Preserve failures and superseded results; do not silently replace them with favourable outcomes.

Keep large dependency installations, private credentials and temporary screenshots out of Git. Use the publication manifest and the engineering verification tool to check that research files remain intact.

Working names have not completed trademark clearance. A public repository does not establish brand availability. No open-source licence has been selected for this project.
